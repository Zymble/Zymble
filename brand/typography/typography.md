# Tipografia oficial

Inter Variable é a família de interface, títulos, marketing, dados e publicidade. Usar os arquivos vetoriais para o nome da marca. O lettering tem contornos ajustados e o ponto do i repete a lâmina central. O arquivo InterVariable.woff2 distribuído é a versão 4.000 de Inter, com eixos de tamanho óptico e peso. Incluir fonts/OFL.txt em redistribuições.

Usar font-variant-numeric: tabular-nums nas métricas, nos tempos e nas colunas numéricas. Usar fallback Inter, system-ui, sans-serif. A partir de 48 rem, adotar os tamanhos desktop quando a linha comportar. Para outras escritas, homologar fallback com falantes da língua de lançamento e conferir quebra, expansão e truncamento.

**Alternativas avaliadas.** Manrope para um tom mais suave, Sora para chamadas tecnológicas, Space Grotesk para linguagem esportiva e Plus Jakarta Sans para comunidade. Inter permite um único carregamento para o painel, o editor e a campanha.

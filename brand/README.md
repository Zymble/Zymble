**Acesso rápido.** Para criar uma peça, abra o manual e importe o SVG oficial diretamente no editor. Para implementar, leia implementation/getting-started.md e carregue variables.css. Para percorrer o fluxo, abra mockups/index.html no navegador e clique em Studio. A galeria Campaign inclui os perfis exemplificativos de TikTok e Discord.

**Escopo.** O usuário aprovou a direção visual. O protótipo usa dados ilustrativos e não incorpora processamento real por IA, autenticação, cobrança ou integrações de publicação. Os ativos gráficos são editáveis e o pacote conserva as alternativas A e C para histórico.
